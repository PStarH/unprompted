title: Keyboard shortcuts
description: Keys in the local app, and the keys for search on this documentation site.

The **?** button in the app header opens the same list inside the product. Pressing `?` is not a shortcut. New tasks and live updates do not take keyboard focus. See [Workspace](workspace.md).

`G`, `N`, `/`, `Z`, and `J` / `K` do nothing while you are typing in a field, while Command, Control, or Alt is held, or while a dialog is open.

## In the app

| Key | Action |
| --- | --- |
| `G` | Go to Overview |
| `N` | Open the next thing that needs you |
| `/` | Search tasks on Overview |
| `Z` | Undo, when a reopen control is visible on the receipt or the toast |
| `J` `K` | On Overview, move through tasks that need you, in on-screen order. In the focus decision queue, step through that queue |
| `Esc` | Close the evidence peek, the open task, or the open memory |
| `Alt` `1`–`5` | Switch the Overview layout. This does not change the sidebar page |
| `⌘` or `Ctrl` `Enter` | Submit a task direction, when that field is focused |
| `←` `→` `Home` `End` | Move between filter tabs when one of them is focused |

Alt+1 through Alt+5 is ignored while you are typing in a field. The five layouts, in order, are **Field** (default), **List**, **Lanes**, **Focus**, and **Changes**. In Chinese those labels are 全局, 列表, 并行, 专注, and 变更.

Command or Control with Enter applies only when the task-direction field is focused.

The filter tabs are **All**, **To review**, **In progress**, **Waiting for input**, and **Finished**.

## On this site

| Key | Action |
| --- | --- |
| `⌘` or `Ctrl` `K` | Open search. Press the same keys again to close it |
| `Esc` | Close search or the mobile menu |
| `↑` `↓` | Move through the search results |
| `Enter` | Open the selected result |
