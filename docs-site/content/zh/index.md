Unprompted 是一个本地优先的原型。它留意你授权的来源，发现那些并没有写成提示词的工作，核对证据，并准备下一步。结果由你审阅。对外动作需要批准，或另一项单独权限。

本站对应当前 `main` 分支，版本 0.3.0。读者有两类：第一次运行应用的人，以及修改代码或调用本地 API 的人。

## 它做什么

```text
授权来源 → 观察到的变化 → 证据核对 → 准备好的工作
        → 你的决定 → 若已许可则对外执行 → 回读
```

- **来源**提供工作内容。本地文件夹不需要云账号。Google、GitHub、Outlook、Slack 和 Notion 使用你自己的账号。
- **模型**解释请求。它不能授予权限，也不能把工作标成完成。
- **工作区**显示需要你处理的、正在进行的，以及正在等待的事项。
- **权限**从只读开始。发送、草稿、文档修改和其他写入都要单独打开。

## 当前边界

应用是一个人、一台机器、一个进程。它绑定 `127.0.0.1`，没有登录。OAuth 令牌、模型密钥和连接器凭据在本机加密保存。保存同步邮件和文档的工作区数据库不加密。来源一开始只读。发送、草稿和其他写入，要等你授权之后才打开。[权限与隐私](permissions.md)写明边界。[连接器](connectors.md)写明每个来源能做什么。

正常启动不会插入示例任务。`npm run demo` 是另一套用完即弃的模拟，不会使用已保存的账号。
