---
title: 连接器
description: 连接每种工作来源和 MCP 工具，选择读取范围并按需允许行动。
---

连接器让 Unprompted 读取你选择的工作，也可以在你允许后使用部分服务的行动能力。先[连接模型](models.md)，再打开**连接**；选择一个来源即可开始，不需要一次全部连接。已有账号由你本人登录，组织账号有时需要管理员批准。

## 先了解两种连接

**工作来源**会在连接后检查内容，并在应用运行时按设置继续观察。默认间隔是五分钟，可在连接页暂停或手动检查。**MCP** 是任务中调用的工具；连接它不会自动轮询或创建任务。同一服务的原生来源和 MCP 分别连接、分别授权。

发行版预置应用身份后，Google、GitHub、Outlook、Slack 和 Notion 原生连接无需你创建开发者应用；如果仍要求 Client ID，请联系发行方。Notion、Linear、Jira/Confluence 和 Todoist 的托管 MCP 使用各自服务商的登录页。

## Google：邮件、文档与日历

1. 在**连接**中选择 **Google → 连接**。
2. 勾选需要观察的 Gmail、Google Docs / Sheets / Slides、主日历。日历初次启用需要重新同意。
3. 如果还需要发送邮件、修改文档或日历，在**附加 OAuth 权限**输入相应权限，使用空格分隔。可用权限见 [Google Workspace](google.md)。
4. 在 Google 页面选择自己的账号，阅读并同意请求，返回应用等待连接完成。
5. 查看连接卡片的账号与最近观察时间；需要时点击**现在检查**。需要行动还要在卡片下允许**平台行动权限**。

可使用**搜索 Google**按邮件查询或按文档名称查找。Google 结果不会自动变成任务。Google 测试应用、组织策略或管理员限制可能影响连接；请联系发行方或组织管理员。

## GitHub：议题、PR、提交与 Actions

1. 用发行方提供的 GitHub App 安装链接，选择自己的账号或组织，并选择允许访问的仓库。组织可能需要管理员批准。
2. 回到**连接 → GitHub**，选择连接。复制显示的设备码，打开 GitHub 官方页面并输入。
3. 在 GitHub 确认授权，回到应用等待账号显示为已连接。
4. 检查仓库选择和最近观察结果。应用可观察分配给你的 issue、提及、需要你处理的 PR，以及近期提交和 Actions。
5. 需要评论或修改时，先确保 App 安装及你的账号拥有相应 GitHub 权限，再在**平台行动权限**中授权。若发行方新增了权限，可能需要重新批准安装。

例如，填写 `/repos/my-org/my-repo` 只覆盖该仓库对应的 API 路径；仓库规则和个人权限仍由 GitHub 决定。

## Microsoft Outlook

1. 选择**连接 → Outlook**，在打开的 Microsoft 页面使用自己的账号登录并同意。
2. 返回应用等待连接。如需邮件管理和发送，在已连接账号的设置中填写**附加 OAuth 权限** `Mail.ReadWrite Mail.Send`，重新授权；其他 Graph 能力需要添加对应权限。
3. 检查账号和连接状态。
4. 连接后会观察收件箱；初次读取近期邮件，之后跟进变化。日历或文件权限不会自动启用这些来源的观察。
5. 需要通用 Graph 行动时，在**平台行动权限**允许账号和目标路径。仅创建草稿也可使用**创建工作成果**中的草稿箱授权。

如果看到需要管理员批准，请联系所在组织。`Mail.ReadWrite` 和 `Mail.Send` 分别控制邮件管理与发送。

## Slack：私信、频道和线程

1. 选择**连接 → Slack**。默认申请私信和群组私信读取；需要观察加入的频道及其线程时勾选频道选项。
2. 需要发送或更新消息时，在**附加 OAuth 权限**填写 `chat:write`。
3. 在 Slack 官方页面选择正确工作区、登录并同意，返回应用确认连接。
4. 如需行动，在**平台行动权限**允许 Slack 的目标 API 路径。消息能否发送到具体频道仍由 Slack 的访问权限决定。
5. 原先只授权私信的用户需要进入**管理连接**重新授权，才能新增频道或写权限。跨工作区安装可能需要管理员批准。

## Notion：选择页面或连接 MCP

**需要观察页面变化：**在**连接 → Notion**选择连接，在 Notion 页面登录、选择工作区和想共享的页面，再返回应用。没有选中的页面不会自动可见。要让应用创建或更新页面，还需发行方的 Notion 集成具备相应能力，再在本机允许平台行动。原生公开发行的可用性取决于发行方的 OAuth 配置。

**只需任务中查找或编辑：**在**连接 → MCP → Notion**点击**登录并连接**，完成 Notion 登录，然后在**工具与权限**选择需要的工具。MCP 登录不会自动开始原生页面观察。

## Todoist：原生观察与 MCP

**持续观察任务：**打开 Todoist 的 **Settings → Integrations → Developer**，取得自己的个人 API token；在 Unprompted 的 **Todoist** 原生连接表单粘贴并连接。这个 token 属于你自己的账号，不要分享给其他用户。任务操作还需在本机允许平台行动。

**任务中调用工具：**选择**连接 → MCP → Todoist → 登录并连接**，在 Todoist 完成登录，然后选择需要的工具。此路径无需粘贴个人 token，但不会自动开启原生任务观察。

## 本地文件夹

1. 在**连接 → 本地文件夹**选择文件夹；macOS 使用系统选择器，其他系统可输入绝对路径。
2. 选择需要观察的范围并确认。应用读取支持的 `.md`、`.markdown` 和 `.txt` 文件，不读取隐藏文件、符号链接和二进制文件。
3. 需要移除某个范围时，在连接详情中移除；需要停止全部读取时断开该来源。

`- [ ]`、`TODO:`、`☐` 等明确标记的待办可以被跟踪。本地文件连接的现有操作范围为读取。

## Apple 备忘录和提醒事项

1. 在 macOS 的**连接**页面选择 Apple 备忘录或 Apple 提醒事项。
2. 接受 macOS 自动化访问提示，选择要观察的备忘录文件夹或提醒事项列表。
3. 如果曾拒绝，在 macOS **系统设置 → 隐私与安全性 → 自动化**中，找到实际启动 Unprompted 的应用并允许对应访问，然后重试。
4. 若要新建 Apple 备忘录，在**连接 → 创建工作成果**中另行允许目标文件夹。

备忘录只读取所选文件夹中的可用文本，锁定的备忘录和附件不在读取范围。提醒事项可以观察所选列表；如需新建提醒事项，在**创建工作成果**中另行允许目标列表。需要修改、完成或删除现有提醒事项时，在**平台行动权限**中单独授权；操作只覆盖选定列表，并会核对最近修改时间。勾选来源中的待办不会自动证明 Agent 已完成任务。

## 内置 MCP 和其他服务

打开**连接 → MCP**：

- **Fetch**：默认开启，无需账号；读取公开网页文本，不渲染网页脚本。
- **Notion、Linear、Jira 与 Confluence、Todoist**：选择对应服务，点击**登录并连接**，在服务商页面同意。组织策略可能要求管理员批准。
- **Brave Search**：在 [Brave Search API](https://api.search.brave.com/)取得自己的 API Key，填入 Brave Search 预设后连接。用于网页搜索。
- **Firecrawl**：在 [Firecrawl](https://www.firecrawl.dev/)取得自己的 API Key，填入 Firecrawl 预设后连接。用于读取网页内容。
- **其他远程服务**：添加服务的 HTTPS MCP 地址，按服务要求登录或提供认证信息；本机地址允许 HTTP。
- **本机服务**：填写命令、参数和服务要求的环境变量，确认程序已安装。该命令以你当前系统用户的权限运行，只连接可信服务。

展开服务的**工具与权限**可选择工具；可写、破坏性或没有只读声明的工具需要明确允许。资源需在**资源与权限**逐项选择。断开服务会使此前获取的工具入口失效。

## 允许行动和检查结果

连接账号不会自动授权所有行动。先在服务商授权页同意所需权限，再打开该账号的**平台行动权限**，选择 API 路径并确认。`/` 覆盖该平台的全部 API 路径，包括账号已获权的发送、修改和删除；也可以填写更窄的路径。路径不一定限制请求正文中的收件人或频道。

需要草稿、Notion 子页面或备忘录时，还可以在**创建工作成果**中授权明确目标。MCP 写工具在对应服务的**工具与权限**中单独选择。显式设置 `UNPROMPTED_SHADOW_MODE=true` 时仍会禁止对外写入。

行动被服务商接受，和独立回读验证成功，是不同状态；结果未知时先核对服务商中的实际内容。有关保存内容和撤权，见[权限与隐私](permissions.md)。

## 断开与排错

**断开连接**停止新的观察并保留本机副本；**断开并清除本机副本**还会删除该来源的本地副本及派生记录，不删除服务商原件。MCP 可在其服务卡片禁用或移除。

- 找不到账号或仓库：确认登录的账号、GitHub 安装范围、Slack 工作区或 Notion 授权页面。
- 能读不能写：重新同意服务商的写权限，并检查本机平台行动或 MCP 写工具是否已允许。
- 回调无法完成：Slack 和 Notion 使用本机 53682 端口，检查是否被其他程序占用。
- 要求 Client ID、应用未获批准或公司管理员限制：联系发行方或组织管理员；普通用户无需自行注册开发者应用。
- 出现部分读取或超时：缩小范围、检查权限后重试；不要把未确认的写入直接重复发送。
