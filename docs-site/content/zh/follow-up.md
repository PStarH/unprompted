---
title: 自动跟进
description: 什么时候可以不再逐次点击就发送或应用准备好的更改，以及这仍然不能跳过什么。
---

默认仍是一次批准一件事。自动跟进是你自己开启的一段授权。它省掉后面的点击，不跳过证据、权限和回读。

影子模式会藏起这些控件，并拒绝请求。显式设置 `UNPROMPTED_SHADOW_MODE=true` 会禁止对外写入，连接器仍需要自己的授权。见[权限与隐私](permissions.md)。

## 两个不同的开关

**本次发送，今后自动**在一份准备好的回复上。它发送这一次，并为该范围记下一条长期约定。设置里的**已约定的自动跟进**列出这些约定。**改为逐次确认**结束约定。已经发出的回复不会被撤回。

**限时自动跟进**是另一套。

- **这件自动跟进**只覆盖一项任务，直到它完成、取消或被放下。重新打开这项任务，不会恢复这段授权。
- **开启限时自动跟进**覆盖当前工作区，包括这段时间里新发现的任务。填写 1–1440 分钟。输入框一开始是 30。你设下的截止时间在重启后仍然有效。

正在生效的授权显示在工作区上方。**停止自动跟进**会结束它。提供商已经接受的写入不会被撤销。

模型的回复不能创建这两种授权。

## 可选的金额上限

时间或任务授权可以附带有限的交易额度，用来约束可能涉及资金的工作。它默认关闭：上限为零。在可选的资金控件中，确认一种币种、一个累计金额和一个独立的有限到期时间。界面金额使用币种单位；API 使用整数微币（1,000,000 微币 = 一个币种单位）。时间额度的金额到期时间不能晚于它的时间授权。任务授权也需要有限的金额到期时间，默认 60 分钟，可在 1–1440 分钟内设置。续期、撤销授权或重启，都不会重置已花金额或未知占用。

额度不会授予提供商、目的地或工具，也不提供价格。付费平台或 MCP 行动需要另一份确认过的契约，把确切的金额和币种字段绑定到该额度。缺少字段、字段不匹配或币种不受支持都会被拒绝，也不会自动换算币种。没有独立资金回读时，服务商接受响应只表示金额仍作为未知占用保留；它不是退款，也不会盲目重试该行动。

模型的 token 与费用限额是另一套设置。它们在模型设置里按工作区或任务配置，使用 UTC 日窗口和你确认的价格。缺少价格或用量时不会当成零成本。见[模型](models.md)。

## 仍然要经过的检查

这段授权可以发送准备好的回复，或应用准备好的文档补丁。它不会打开新的目的地，也不会授予连接器写入。如果另设了交易额度，它还可以约束另行授权的付费平台或 MCP 行动。

暂停的任务，或还要再审一遍、还要重新读取的任务，不会自己执行。提供商结果不确定时，任务会显示**自动执行已暂停**，同一次尝试不会盲目重试。

## API

`POST /api/autonomy`

```json
{ "mode": "time", "durationMinutes": 30 }
```

```json
{ "mode": "task", "taskId": "TASK_ID" }
```

```json
{
  "mode": "time",
  "durationMinutes": 30,
  "money": {
    "currency": "USD",
    "capMicros": 1000000,
    "durationMinutes": 20,
    "confirmed": true
  }
}
```

这里配置的是额度，不会发起付款，也不会授予工具访问。响应包含 `grant` 和 `state`。同一模式、同一任务的新授权会替换上一条。同一范围和币种的多次授权共享累计账目；续期、到期和重启都不会重置已花金额或未知占用。时间授权和任务授权可以同时存在。`POST /api/autonomy/GRANT_ID/revoke` 停止该授权。`GET /api/state` 包含 `autonomy.enabled` 和当前有效的授权。

无效输入返回 **400**。影子模式下的错误文本是 `YOLO requires write mode.`
