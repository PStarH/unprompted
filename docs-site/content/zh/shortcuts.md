---
title: 键盘快捷键
description: 本地应用里的按键，以及本站搜索用的按键。
---

应用顶栏的 **?** 按钮会打开产品里的同一份列表。按下 `?` 不是快捷键。新任务和实时更新不会抢走键盘焦点。见[工作区](workspace.md)。

在输入框里打字、按住 Command、Control 或 Alt，或有对话框打开时，`G`、`N`、`/`、`Z` 和 `J` / `K` 都不起作用。

## 在应用里

| 按键 | 作用 |
| --- | --- |
| `G` | 回到工作台 |
| `N` | 打开下一件需要你的事 |
| `/` | 在工作台搜索任务 |
| `Z` | 撤销。回执或提示上要有可见的重新打开控件 |
| `J` `K` | 在工作台上，按屏幕顺序在需要你的事之间移动。在专注决策队列里，则顺着那个队列移动 |
| `Esc` | 关闭证据浮层、打开的任务，或打开的记忆 |
| `Alt` `1`–`5` | 切换工作台的五种视图，不是侧栏页面 |
| `⌘` 或 `Ctrl` `Enter` | 焦点在任务纠偏输入框时，提交任务纠偏 |
| `←` `→` `Home` `End` | 焦点在筛选标签上时，在筛选之间移动 |

在输入框里打字时，Alt+1 到 Alt+5 不起作用。五种视图依次是 **全局**（默认）、**列表**、**并行**、**专注**、**变更**。英文界面里是 Field、List、Lanes、Focus、Changes。

Command 或 Control 加 Enter，只在任务纠偏输入框获得焦点时生效。

筛选标签是 **全部**、**待你处理**、**正在处理**、**等待回复或资料**、**已结束**。

## 在本站

| 按键 | 作用 |
| --- | --- |
| `⌘` 或 `Ctrl` `K` | 打开搜索。再按一次关闭 |
| `Esc` | 关闭搜索或移动端菜单 |
| `↑` `↓` | 在搜索结果之间移动 |
| `Enter` | 打开选中的结果 |
