Privacy policy

Last updated: October 30, 2026

This notice explains the data handling of this static website and the open-source, locally run Unprompted application. They have different data flows.

This website

The landing page does not include project-operated analytics, advertising trackers, account registration, or forms that collect personal information. Fonts, images and animation scripts are served with the site. The Copy button writes the displayed installation commands to your clipboard only when you press it. The animation preference is kept in memory for the current page and is not saved to your device.

The production website is intended to be hosted on GitHub Pages. GitHub processes request information, including IP addresses, to provide its hosting service. See GitHub’s Privacy Statement for its practices. Links to GitHub and other external websites take you to services with their own privacy terms.

The local application

Unprompted runs a server on your machine and stores a local workspace. This may include synchronized email and document content, selected local files, discovered requests, evidence excerpts, drafts, task history, memories, and connection credentials. There is no project-hosted application backend or analytics endpoint in the current implementation.

The local server binds to localhost and has no built-in authentication. Keep it on your own machine. Local workspace data, saved tokens, and model keys are not encrypted at rest. Operating-system file permissions help restrict access where supported; they do not replace disk security.

Connected sources and models

Reading a cloud source contacts that provider. Enabling a model sends selected task context, which can include email and document content, to the model endpoint you configure. A local compatible model can avoid a remote model endpoint. Each provider’s own terms and retention practices apply; this project cannot determine or promise those practices for you.

Connect only sources you are authorized to use. Sources start read-only. Draft creation, sending, document edits, and other external writes require the relevant separate grants and approval or an explicitly scoped standing authorization. A learning or memory setting does not grant write permission.

Your controls and retention

You can pause observation, manage connector permissions, inspect task history, and edit or delete memories. Disconnecting a source stops new reads but retains the saved local copy. Use Disconnect and clear to remove the source’s local inbox, tasks, snapshots and derived records. Forget reports its local cleanup and any unresolved operations or retention limits.

These controls do not remove messages or documents already held by a connected provider, data already sent to a model endpoint, or independent copies you made outside the app. Review the configuration and storage documentation for the current implementation and backup behavior.

Feedback and questions

Information you choose to put in a public GitHub issue or pull request becomes public. Use synthetic examples. Never post workspace databases, access tokens, model keys, private messages, or sensitive documents. Use the security reporting instructions for sensitive vulnerability reports. General questions can go through the project issue tracker.

Changes

This notice will be updated when the website or application’s data handling changes. The date above identifies this version; repository history records changes.
