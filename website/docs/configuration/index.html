Configuration

People using the app set the model and sources in the interface. Environment variables are for operators and local development.

Modes#

CommandWorkspaceCredentialsWrites
npm run demoTemporary simulationSaved model and Google setup are ignoredSimulated local outbox only
npm startPersistent local workspaceIn-app setup, or variables you exportedRead-only until a write is explicitly enabled
node --env-file=.env server.jsPersistent, or UNPROMPTED_STATE_FILEThe .env file you nameRead-only unless you enable writes

npm start does not read .env. Copy .env.example only for the settings you need. The file is gitignored.

Where files live#

Setup is setup.json in the platform config directory. On macOS that is ~/Library/Application Support/Unprompted. Linux uses ${XDG_CONFIG_HOME:-~/.config}/unprompted. Windows uses %APPDATA%\Unprompted. The directory mode is 0700 and the file mode is 0600 where the system supports it.

UNPROMPTED_CONFIG_DIR and UNPROMPTED_SETUP_FILE override those paths for development. MCP credentials are in mcp.json beside the setup file. A normal state path ending in *-state.json is stored as SQLite. Do not edit the database while the process is running.

Ship the connectors#

A distribution registers each OAuth application once. People using the app then authorize their own accounts. They do not paste access tokens. The build carries client metadata only. Connectors describes that finished path.

AppWhat the build includesWhat the user does
GitHubA public client ID, device flow, and read access to Issues, pull requests, contents, Actions, and Metadata. Do not request the repo scopeGet authorization code
OutlookA public client ID and browser authorization with PKCE; register http://localhost/oauth/microsoft as a mobile and desktop redirect. Delegated openid, profile, offline_access, User.Read, and Mail.Read. Drafts later add Mail.ReadWriteConnect, then sign in and consent
SlackA client ID and secret, with PKCE. Redirect http://localhost:53682/oauth/slack. User scopes im:read, im:history, mpim:read, mpim:history, and users:read. No bot or write scopeConnect
NotionA client ID and secret. Redirect http://localhost:53682/oauth/notion. Read content, read user information, and Insert content when users will create pagesConnect
GoogleA Desktop client file, with no user refresh tokenConnect Google

GitHub, Outlook, Slack, and Notion can live in gitignored connector-clients.json, or in the file named by UNPROMPTED_CONNECTOR_CLIENTS_FILE. The environment names are UNPROMPTED_GITHUB_CLIENT_ID, UNPROMPTED_MICROSOFT_CLIENT_ID, UNPROMPTED_SLACK_CLIENT_ID, UNPROMPTED_SLACK_CLIENT_SECRET, UNPROMPTED_NOTION_CLIENT_ID, and UNPROMPTED_NOTION_CLIENT_SECRET. A browser-login pair is used only when both values are present.

Google uses google-oauth-client.json, --google-client, or UNPROMPTED_GOOGLE_DESKTOP_CLIENT_ID and UNPROMPTED_GOOGLE_DESKTOP_CLIENT_SECRET. The macOS app builder accepts --connector-clients and --google-client, keeps that metadata, and drops account tokens. While a Google app is in Testing, refresh tokens last about seven days, and only listed test users can connect.

Slack and Notion exchange the code on the user's machine, so those secrets travel with the build. They are not held on a confidential server. Registration steps are in the repository's connector guide.

Stop and reset#

Ctrl+C stops the process. Stop it before you move the state file. One process may write a state file. The demo can be run again for a fresh simulation. A control that resets the demo is refused when the workspace holds real events.
