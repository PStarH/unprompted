故障排查

本页目录
  1. 仍然卡住

报告里不要包含凭据、邮件和状态文件。

你看到的怎么处理
找不到 node 或 npm安装 Node.js 20 或更新版本，新开一个终端，运行 node --version。
ENOENT，或找不到 package.jsoncd 到包含本项目 package.json 的目录。
端口 4173 被占用启动器会打印另一个地址。用 --port 指定的端口若被占用，启动会失败。换一个端口。
浏览器连不上使用 Ready 之后打印的那一行 http://127.0.0.1:PORT/。服务只在那台机器上。
.env 像是没生效npm start 不会加载它。使用 node --env-file=.env server.js，或自己导出变量。
模型连不上验证是一次真实请求。失败会保留之前的连接。检查接口地址、模型 ID 和密钥。
没有新内容确认已经连接模型和至少一个来源，看读取数量，并选择现在检查。零条也可以是真实结果。正常模式不会插入示例。
授权没有完成卡片上会说明原因。重新连接即可。授权码过期后，会生成新的授权码。如果授权已经保存，选择应用已保存的连接，不必再次登录。
Google 邮件发不出去发送需要单独的权限范围、GOOGLE_SEND_ENABLED、关闭影子模式，以及一次批准。这条路径有脚本测试，没有生产验证结论。
STATE_LOCKED另一个正常模式进程占用了该状态文件。停掉它，或换一个状态文件。不要删除正在使用的锁。
备忘录权限提示在 macOS 上，允许启动 Unprompted 的应用使用自动化，通常是终端。锁定的备忘录会被跳过。
写入被拒绝检查平台权限和本机行动授权；显式设置 UNPROMPTED_SHADOW_MODE=true 会强制只读。
