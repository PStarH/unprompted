使用指南

权限与隐私

读取从你连接来源时开始。写入不会跟着打开。服务只在本机，没有登录。不要用隧道、反向代理或公网主机把它暴露出去。

默认#

  • 来源默认先读取；平台行动需服务商权限和本机账号、API 路径授权。/ 覆盖所有平台 API 路径。
  • Google 专用发送和 Docs 修改流程有各自的行动设置。见 Google Workspace。
  • GitHub、Slack、Outlook、Notion、Google、Todoist 的通用 API 行动取决于服务商实际授予的权限，以及本机允许的范围。Apple 备忘录新建需要文件夹授权。
  • 可写、破坏性或没有只读声明的 MCP 工具需要单独允许；导入配置不会自动授权写入。
  • 模型不能自行授予这些权限。显式设置 UNPROMPTED_SHADOW_MODE=true 时，影子模式会拒绝外部写入。

每一次真实动作仍需要你的批准，或与之匹配的长期授权。提供商结果不明时，会先核对再决定是否重试，不会当成成功。

存了什么#

正常模式在本机保存 SQLite 工作区。其中可以有同步来的邮件、文档、本地文本、证据摘录、草稿和动作历史。请把它当作个人数据。工作区数据库不加密。不要把它附到议题里。

OAuth 令牌、模型密钥和连接器凭据在写入私有设置文件或旁边的 mcp.json 之前加密。macOS 上目录是 ~/Library/Application Support/Unprompted，密钥放在登录钥匙串。Linux 在可用时使用会话密钥环。Windows 使用 DPAPI。如果第一次运行时操作系统密钥库不可用，密钥会放在同一目录里权限为 0600 的文件中。系统支持时，目录权限为 0700，文件权限为 0600。API 不返回这些秘密。已有安装会在下次启动时密封这些凭据，不需要重新登录。以同一系统用户运行的进程仍能读到密钥。

没有项目分析端点。已连接的提供商，以及启用的模型接口，会收到完成调用所需的内容。

断开、清除和忘记#

  • 断开连接停止新的读取，并保留本机副本。
  • 断开并清除本机副本删除该来源在本地的收件、任务、快照和派生记录。它可能先等当前同步结束。
  • 忘记删除你选定的本地记录，并报告还没做完的清理，包括仍在读取数据库的部分，以及你登记过的副本。它不会删除提供商那里的原件，也不会撤回已经发给模型的请求。

「不要再这样做」是一条单独的抑制规则，不是忘记。
