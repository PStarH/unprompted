这是 1.0 之前的预览。下面只概括已经发布的 0.3.0，日期是 2026-10-28。全文在仓库的更新记录。

0.3.0#

你连接自己的模型，以及你授权的来源。另一套演示用虚构数据走一遍循环：事件、证据、被授权的动作，然后是核验过的结果。

第一次运行#

  • 首页上的来源：本地文件夹、macOS 上的 Apple 备忘录、Google、GitHub、Outlook、Slack 和 Notion。多个来源可以同时启用，不必重启。断开也是各自独立的。
  • 用 npm start 启动，然后验证并连接模型。要先得到一次真实的结构化响应，连接才会保存。密钥不会进入工作区、API 或事件流。
  • GitHub 和 Outlook 使用设备授权，并在启用前核对已登录的账号。Google 的同意不用重启即可生效，并读取最近的邮件和已有的 Docs。
  • Gmail 和 Outlook 可以保存草稿。Notion 和 Apple 备忘录可以在你另外授权的目的地里创建内容。发送是单独的授权。GitHub 和 Slack 保持只读。
  • 中文和英文跟随浏览器语言。默认端口被占用时，启动会打印另一个地址。

这一版写明的限度#

  • 测试使用虚构数据和脚本化的提供商。它们不能证明真实用户价值，也不能证明提供商在生产环境里可靠。
  • 一个本地用户，每个存储一个写入者。扩展接口还不是稳定的 SDK。
  • macOS 构建器可以产出未签名的审阅包。签名和公证是另外的发布工作。本站不提供这个下载。
  • 真正未经请求就发现的工作，仍然是验证的优先事项。

安装见安装与首次运行。指出不足见参与贡献。
