这些回答对应当前应用。每一条都链到更完整的页面。

它在云上运行吗？#

不在。npm start 绑定这台机器的 127.0.0.1。没有登录，也没有托管的工作区。不要用隧道或反向代理把这个端口公开出去。见安全。

需要注册 Unprompted 账号吗？#

不需要。你连接自己的模型，并授权自己的来源账号。发行版可以预先登记好连接器应用。开始使用时不必粘贴 Client ID。见连接器。

它会自己发信或改文档吗？#

来源一开始只读。发送、草稿、文档修改和其他写入都要单独授权。保存草稿不会把信发出去。显式设置 UNPROMPTED_SHADOW_MODE=true 时，影子模式会挡住外部写入。见权限与隐私。

它可以替我批准下一步吗？#

只有你开启自动跟进之后才可以。这段授权能发送准备好的回复，或应用准备好的文档补丁。证据、权限和影子模式仍然不能跳过。

连上来源，就可以在那里创建内容吗？#

不可以。创建工作成果是另一项授权。目的地是 Gmail 草稿、Outlook 草稿、Notion 子页面和 Apple 备忘录文件夹。GitHub 和 Slack 的通用行动需要服务商权限与单独的本机授权；本地文件连接当前只读取。见连接器。

断开连接和忘记有什么区别？#

断开连接停止新的读取，并保留本机副本。断开并清除本机副本删掉这个来源的本地记录。忘记删掉你选定的一条本地记录，并报告还没做完的清理。它不会删除提供商那里的原件，也不会撤回已经发给模型的请求。「不要再这样做」是抑制规则，不是忘记。

为什么启动时要验证模型？#

验证并连接模型会用示例内容发一次结构化请求。失败不会保存这次候选。密钥留在私有设置文件里。见模型。

为什么 .env 没有生效？#

npm start 不读取 .env。在 Node.js 20.6 或更新版本上使用 node --env-file=.env server.js，或自己导出变量。见配置。

npm run demo 是我的工作区吗？#

不是。那是一套用完即弃的模拟。它不用已保存的账号，也不会往正常工作区里插入示例任务。

数据存在哪里？加密吗？#

工作区是本机的 SQLite 文件，不加密。OAuth 令牌、模型密钥和连接器凭据在平台配置目录中加密保存。macOS 上是 ~/Library/Application Support/Unprompted，密钥放在登录钥匙串。系统支持时，目录权限为 0700，文件权限为 0600。见权限与隐私。

可以连接哪些来源？#

本地文件夹、macOS 上的 Apple 备忘录、Google Workspace、GitHub、Outlook、Slack 和 Notion。MCP 是可选的查找，不是任务来源。见连接器。

模型可以把工作标成完成吗？#

不能。它不能批准动作、授予权限，或宣布工作完成。核验过的结果，要在一次被允许的动作之后完成回读。见工作如何推进。

应该安装什么？#

Node.js 20 或更新版本，然后 npm ci --include=optional，再 npm start。打开 Ready 之后打印的地址。Pi 运行时需要 Node.js 22.19 或更新版本。没有经过公证的 Mac 下载。见安装与首次运行。

怎么反馈问题？#

缺陷、界面问题、这些页面里的错误，以及功能建议，可以发公开议题。不要附上凭据、邮件和状态文件。漏洞走安全里的私下渠道。改代码从参与贡献开始。
