开始使用

概览

本页目录
  1. 它做什么
  2. 当前边界
  3. 接着读
  4. 欢迎改进

Unprompted 是一个本地优先的原型。它留意你授权的来源，发现那些并没有写成提示词的工作，核对证据，并准备下一步。结果由你审阅。对外动作需要批准，或另一项单独权限。

本站对应当前 main 分支，版本 0.3.0。读者有两类：第一次运行应用的人，以及修改代码或调用本地 API 的人。

它做什么#

text
授权来源 → 观察到的变化 → 证据核对 → 准备好的工作
        → 你的决定 → 若已许可则对外执行 → 回读
  • 来源提供工作内容。本地文件夹不需要云账号。Google、GitHub、Outlook、Slack 和 Notion 使用你自己的账号。
  • 模型解释请求。它不能授予权限，也不能把工作标成完成。
  • 工作区显示需要你处理的、正在进行的，以及正在等待的事项。
  • 权限从只读开始。发送、草稿、文档修改和其他写入都要单独打开。

当前边界#

应用是一个人、一台机器、一个进程。它绑定 127.0.0.1，没有登录。本地数据库、令牌和模型密钥都不加密。来源一开始只读。发送、草稿和其他写入，要等你授权之后才打开。权限与隐私写明边界。连接器写明每个来源能做什么。

正常启动不会插入示例任务。npm run demo 是另一套用完即弃的模拟，不会使用已保存的账号。

接着读#

  • 安装与首次运行 — 先 npm ci --include=optional，再 npm start。
  • 模型 — 接口地址、模型 ID，以及可选的 API 密钥。
  • 连接器 — 本地文件夹、Apple 备忘录、Google、GitHub、Outlook、Slack、Notion 和 MCP。
  • 工作区 — 工作台、记忆、连接和设置。
  • 自动跟进 — 你自己开启的一段授权，检查仍然不能跳过。
  • 本地 API — 本机 HTTP 接口。
  • 开发与测试 — 检查一次改动要跑的命令。
  • 参与贡献 — 反馈、拉取请求，以及一次改动需要的检查。

本站还有：键盘快捷键、常见问题、术语、更新记录、安全。

欢迎改进#

产品哪里不够，可以直接说。界面和前端、小缺陷、文档错误、新功能，都欢迎。短短一条就够。不需要邀请，中文或英文都可以。参与贡献写了怎么反馈，以及怎么把改动交上来。
