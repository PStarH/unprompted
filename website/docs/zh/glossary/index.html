来源#

应用被允许读取的地方。本地文件夹、Apple 备忘录、Google、GitHub、Outlook、Slack 和 Notion 都是来源。连上一个来源，不等于可以写入。

观察#

对已连接来源的一次读取。连上时会检查一次，之后按「连接」里保存的间隔重复。默认是 5 分钟。可选 1 分钟、5 分钟、15 分钟或 1 小时。可以暂停，也可以选现在检查。进程需要保持运行。读到零条也可以是真实结果。这是轮询，不是 webhook。

证据#

用来核对一条要求的原始材料。证据缺失或过期时，工作保持开放。模型的回复本身不是证据。

审阅令牌#

附在一份准备好的草稿上的那个确定值。批准时送出的就是它。草稿或它的输入变了，旧令牌会被拒绝，任务需要再次审阅。

回读#

一次被允许的写入之后，再读回提供商的结果。只有这次回读才算核验过的结果。结果不确定时，会先核对，再决定是否重试。

影子模式#

显式设置 UNPROMPTED_SHADOW_MODE=true 会挡住外部写入。连接器仍需要自己的授权。

主角色#

模型连接保存之后的理解方式，或设置了 UNPROMPTED_MODEL_ROLE=primary 时的方式。规则仍可以识别请求。模型仍会被调用，原来可以核验的要求继续有效。

辅助模式#

没有设置模型角色时沿用的旧方式。只在规则覆盖不到的地方，请模型补充解释。

Pi 运行时#

用 UNPROMPTED_AGENT_HARNESS=pi 选中的可选循环。它使用 Pi Agent Core 1.4.0，需要 Node.js 22.19 或更新版本，每次最多四次模型请求、八次工具尝试、60 秒。默认运行时是 classic。

自动跟进#

你自己开启的一段授权，用来发送准备好的回复，或应用准备好的文档补丁，不必再点一次。影子模式会拒绝它。它不授予连接器写入。见自动跟进。

长期目标#

在你确认的范围内观察或准备的一条指令。审阅之前它留在本地。它不会授予连接器写入。在记忆页创建和暂停目标。

断开连接#

停止从来源读取新内容。本机副本会保留，直到你选择断开并清除本机副本。

忘记#

删掉你选定的一条本地记录，并报告还没做完的清理。它不会删除提供商那里的原件，也不会撤回已经发给模型的请求。

工作成果#

应用在你另外授权的目的地里创建的东西：Gmail 草稿、Outlook 草稿、Notion 子页面，或一条 Apple 备忘录。保存它不会发信，也不会把来源任务标成完成。

MCP#

连接页里的可选工具查找。工具和资源在你允许读取之前保持关闭。可写和破坏性的工具保持阻止。它不是任务来源。

演示#

npm run demo。一套用虚构数据、用完即弃的模拟。它不用已保存的账号，也不是持久工作区。
