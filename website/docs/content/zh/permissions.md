## 读取与写入分开

Unprompted 从只读契约开始。连接账号或选择文件夹只授予观察权限。写入需要单独的目标授权，通常还需要独立的服务商范围和提供方开关。

| 层 | 控制什么 |
| --- | --- |
| 连接 | 应用可以读取的账号或文件夹。 |
| 读取范围 | 观察哪些内容。缺少范围就不能读取。 |
| 目标授权 | 写入可以指向的具体邮箱、父页面或文件夹。与读取连接分开。 |
| 提供方开关 | 写入适配器的环境或设置开关，例如 `GOOGLE_SEND_ENABLED`。 |
| 操作批准 | 由人批准这次操作，或由有范围的 YOLO 租约覆盖。 |
| 派发检查 | 操作时重新检查来源、负载、版本、隐私、连接和目标。 |
| 回读 | 服务商已接受的操作，在回读前不会报告为已验证。 |

已接受但未确认的外部操作会保持可见，并阻止重试，直到完成对账。影子模式拒绝外部写入，包括模拟发送。

## 批准与 YOLO

单独批准是默认方式。准备好的操作带有一个审阅令牌，绑定其当前版本。如果来源、指导或目标变化，令牌失效，操作返回 `REVIEW_CHANGED`。

YOLO 是可选的自动批准：

- **任务 YOLO** 覆盖一个任务，直到完成、取消、拒绝或不可用。
- **时间 YOLO** 覆盖当前工作区 1–1440 分钟，包括期间发现的任务。

YOLO 是已保存的用户授权，不是模型决定。模型响应或工具参数不能创建租约。暂停的任务和需要审阅变化指导的任务不会自动继续。过期在派发时检查。撤销租约只停止尚未派发的操作，不能撤销服务商已经接受的操作。

## 什么留在本地

没有项目托管的后端，也没有分析端点。服务器绑定 `127.0.0.1`。正常模式可以把同步的邮件、文档内容、本地文件摘录、请求、证据、草稿和操作历史保存在本地 SQLite 工作区。

平台应用支持目录保存 `setup.json`：

| 平台 | 默认位置 |
| --- | --- |
| macOS | `~/Library/Application Support/Unprompted` |
| Linux | `${XDG_CONFIG_HOME:-~/.config}/unprompted` |
| Windows | `%APPDATA%\Unprompted` |

`UNPROMPTED_CONFIG_DIR` 选择其他目录；`UNPROMPTED_SETUP_FILE` 指定具体文件。POSIX 系统上目录权限为 `0700`，设置、模型和 MCP 文件在支持时为 `0600`。**凭据在本机加密保存。工作区数据库不加密。** 请使用全盘加密和私人账号。以同一系统用户运行的进程仍能读到密钥。

已连接的云来源会联系其服务商。启用的模型会联系配置的端点。界面使用系统字体，不请求第三方字体。演示不调用服务商、模型或外部字体。

## 什么会离开你的机器

| 目的地 | 可能发送的内容 |
| --- | --- |
| 你的模型端点 | 提示词、请求、选中的来源摘录，以及当前任务需要的工具结果。 |
| Google | API 读取；只有单独启用并批准后才写入。 |
| GitHub | API 读取。不会评论、审阅、合并或修改工作流。 |
| Microsoft Graph | 邮件读取；只有单独授权后才创建草稿。 |
| Slack | 消息读取。 |
| Notion | 页面读取；只在已授权父页面下创建子页面。 |
| MCP 服务器 | 工具参数以及服务器返回的内容。请审阅每个服务器和工具。 |

只读模式阻止通过 Unprompted 写入，但不会阻止任务上下文发送给模型服务商，也不会改变该服务商的保留或训练政策。

## 本地 API 暴露

本地 API 没有身份验证。来源检查和 JSON 要求可以减少浏览器跨站滥用，但它们不是登录，也不能防止同一台机器上的其他进程。不要把端口暴露到网络，不要把工作区放在公共或共享目录。

## 删除数据

- **忘记此上下文** 在确认后删除选中的记忆与任务上下文。
- **断开** 停止该来源的观察和操作。本地历史保留。
- 删除记忆或本地记录不会删除原始邮件、文档或服务商数据。
- 要撤销服务商授权，请使用服务商的已连接应用设置。
- 备份、移动或删除状态文件前先停止进程。不要删除活动锁。

不要在 bug 报告中附加状态文件、OAuth 令牌、模型密钥、真实邮件或文档内容。

## 隐私检查清单

1. 从本地文件夹和虚构内容开始。
2. 一次连接一个云来源，检查实际读取范围。
3. 在理解准备好的操作前保持影子模式开启。
4. 使用数据政策与所连内容相匹配的模型端点。
5. 让应用只在本机运行，并保持状态目录私有。
6. 不再需要时删除本地状态并撤销服务商授权。
