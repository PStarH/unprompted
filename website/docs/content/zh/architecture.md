## 一件工作的路径

```text
授权事件
  → 规范化上下文
  → 请求或承诺
  → 证据与策略评估
  → 有界推理 / 探查
  → 准备好的操作
  → 用户决定或范围租约
  → 幂等派发
  → 服务商回读
  → 已验证结果或对账
```

模型在任务租约内解释和规划。确定性代码负责来源身份、关联、证据要求、权限、审阅令牌、派发与验证。

## 先有证据，再有操作

只有内容要求被可验证证据满足时，操作才进入可执行状态。缺失或过时的证据会让工作保持打开。更新的来源结果可以撤回已准备的草稿。模型的信心不是证据；主解释模式启用时，可被规则识别的请求仍会调用模型。

就绪状态记录为有来源依据的审阅。模型不能移除原始可验证要求。失败或缺乏依据的模型推理会保留确定性评估，不会变成仅靠规则的可用回复。

## 存储与进程模型

正常模式使用一个本地 SQLite 工作区，启用 WAL 与 FTS5。进程锁防止两个进程同时写入同一状态文件。状态以原子方式写入，并在操作系统支持时使用限制性权限。它未加密。

工作区可能包含来源内容、请求、证据摘录、草稿、操作历史，以及有界的模型/MCP 调用记录。请把它当作个人数据。界面连接的云账号在同一配置目录中使用单独的哈希状态文件。

演示是独立的临时工作区，不会继承真实 Google 凭据，也绝不会把示例记录插入正常启动。

## 执行与恢复

外部操作是幂等的，并绑定已审阅的来源、负载、版本、目标授权和隐私状态。影子模式拒绝写入。派发时再次检查授权。服务商接受的操作在回读确认前不算完成；不确定结果保持阻断，直到对账。

等待跨重启持久化。任务暂停会停止评估和新的外部执行。修正会使准备好的工作与保存的验证计划失效，然后重新检查证据。重新打开已关闭任务会重建草稿，但不会发送。

## 推理预算

classic 适配器通常只发起一次服务商调用；启用 MCP 工具时除外。Pi 增加只读工具循环，并有明确预算：

- 每次运行最多四次模型请求、八次工具尝试和 60 秒；
- 每次服务商请求 2,048 个输出 token、20 秒，且不进行 SDK 重试；
- 32,000 个序列化上下文字符；
- 最多八份关联文档，每片段 4,000 字符。

超限或格式错误会明确失败。完成的探查计划按任务检查点保存。进行中的对话不会在进程重启后恢复；有界持久任务可以被重建，但不会重放部分执行的对话。

## 接口

- 浏览器工作区由 `server.js` 从 `public/` 提供。
- 本地 API 无身份验证，正常使用时仅限 localhost，并对写入执行来源检查。
- SSE 发送完整快照，有界缓冲并带心跳。
- MCP 是客户端集成。服务器读取注解只是声明，不是沙箱；没有注解的工具需要显式授权，可写或破坏性工具保持阻断。

## 已实现与实验性

有自动化覆盖的实现包括：事件引擎、关联、证据检查、策略、持久化和工作区 UI。脚本覆盖包括 Gmail 发送与回读、文档补丁、等待、修正和自动批准。

已实现但未在此声称生产验证：Google、GitHub、Outlook、Slack、Notion 的真实账号；Apple 备忘录真机自动化；签名 macOS 应用。云集成需要已注册 OAuth 客户端，部分服务商审核仍需人工完成。Google 发送与 Docs 写入有显式开关，并针对脚本传输测试。

未实现：日历、通用桌面控制、不受限制的自主文档改写、托管服务、身份验证和多用户租户。

## 已知限制

- 数据库、令牌和密钥未加密。
- 没有内置身份验证或多用户隔离。
- 未启用服务商推送；观察使用轮询和有界续传。
- 不确定的外部结果在对账前不能重试。
- 模型与服务商行为可能变化；本地测试通过不代表远程服务保证。
- API 可能在 1.0 前变化。
