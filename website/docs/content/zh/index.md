## 这份文档覆盖什么

Unprompted 是一个本地优先的工作伙伴。它观察你授权的来源，发现没有人明确交办但值得处理的事，核对证据，准备好下一步，并在行动前询问你。

这些页面对应当前 `main` 分支和 v0.3.0 版本。读者有两类：第一次运行应用的人，以及修改代码或调用本地 API 的人。

## 各部分如何衔接

```text
授权来源 → 观察到变化 → 核对证据 → 准备工作
        → 你决定 → 外部操作（若获授权） → 回读结果
```

- **来源**提供工作与上下文。本地文件夹不需要云账号；Google、GitHub、Outlook、Slack 和 Notion 使用你自己的账号。
- **模型**理解请求、关联上下文。它不能授予权限，也不能宣布任务完成。
- **工作区**显示什么需要你、什么正在推进、什么在等待，并保留每项结果背后的证据。
- **权限**从只读开始。发送、创建草稿、编辑文档和写入来源都需要单独授权。

## 工作区一览

![工作页：一个总数、一句状态说明、四个状态区，以及 Agent 正在观察和最近做过的事。](../../assets/ui-work.png)

界面刻意保持安静。新任务和实时更新不会自动打开详情、抢走焦点或打断输入。任务视图、记忆、连接和设置见[工作区](workspace.md)。

## 当前范围

这是一个本地、单用户、单进程实现。它运行在你的机器上，绑定 `127.0.0.1`，没有内置身份验证。OAuth 令牌、模型密钥和连接器凭据在本机加密保存。保存同步邮件和文档的工作区数据库不加密。连接敏感工作前请阅读[权限与隐私](permissions.md)。

仓库不附带公共 OAuth 客户端。云来源需要你注册的客户端，或包含客户端的发行版。部分连接器的真实账号验收仍未完成；当前边界见[连接器](connectors.md)。
