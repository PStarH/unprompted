## 四个入口

导航栏有 **工作（Work）**、**记忆（Memory）**、**连接（Connections）** 和 **设置（Settings）**，设置固定在底部。工作区刻意保持安静：新任务和实时更新不会自动打开详情、抢走焦点或打断输入。

## 工作

页面顶部是一个总数，以及一句说明 Agent 正在做什么的话；有下一步时会只显示一个下一步操作。四个区域即使为空也保留：

- **需要你** — 一个决定、缺失的证据、权限提示，或变化的目标。
- **进行中** — 已获授权、正在准备或派发的工作。
- **等待** — 正在等待某个人、来源或外部结果，且该等待已持久化。
- **观察中 · 已暂停 · 已完成** — 正在观察的来源、暂停的工作和已验证的结果。

每个任务是一条安静的行，带状态标记、标题和当前正在发生的事。混合状态的区域还会用文字注明状态。区域下方是背景面板，只根据已记录状态显示 Agent 在观察什么、最近四个动作和保留了多少条记忆。没有来源时会说明并链接到连接。

### 审阅任务

选择任务会在区域下方就地打开详情，不会自动选中任何任务。左栏先显示非最终结果——未确认、失败、来源断开、状态未知——再显示决定，最后是调整方向。右栏显示带证据摘录的要求清单、来源和任务自身历史。

![任务详情：结果、决定与证据清单。](../../assets/ui-task.png)

关闭详情会保留草稿，并把焦点还给原来的行。共享等待——一个能解开多个任务的回答——会作为一条区域出现在上方。

### 五种视图

在设置中选择表示方式。五种视图使用同一份任务数据：

| 视图 | 用途 |
| --- | --- |
| **Field** | 默认总览，包含四个区域和来源摘要。 |
| **List** | 紧凑浏览所有任务。 |
| **Lanes** | 并排查看任务状态。 |
| **Focus** | 一次只处理一个决定。 |
| **Changes** | 变化记录，包括准备和后续跟进。 |

在任务列表中，`J` 和 `K` 按屏幕顺序在需要你的任务间移动。输入时不会生效。实时更新不会改变已打开的任务。

## 记忆

记忆保存 Agent 对你的工作了解到的内容。总览显示每个范围的数量、简短预览和明确保存的交付物。打开范围后，范围列表变成窄索引，记忆占据主宽度。

Library 按范围分组，可按最近更新或内容排序。事实、规则和执行经验保留各自的管理区域。你可以编辑、删除、搜索、筛选和恢复记录。范围之间不绘制关系，因为存储中没有显式关系记录。

记忆不是什么：

- 不是每个来源事件的完整记录。
- 不是服务商副本。删除记录不会删除来源文档或邮件。
- 不能授予权限，也不能替代缺失的证据。

**忘记此上下文** 会在明确确认后删除选中的记忆与任务上下文。保存敏感细节前请阅读[权限与隐私](permissions.md)。

## 连接

连接页按状态分组显示实际来源，并用文字说明访问权限：读取开启、修改开启、关闭、需要处理，或连接。每行显示账号、最近观察、条目数量和可用操作。数量也可用于筛选。这里不列出观察到的上下文。

你可以连接多个来源、暂停观察、重试失败的读取，并在保留其他账号的情况下断开某一个账号。要为某个目标准备草稿、新备忘录或文档补丁，必须先有单独的目标授权。

MCP 服务器在单独区域。工具授权按单个工具生效；仅有资源的服务器需要逐个选择资源。见[连接器](connectors.md)中的 MCP 部分。

## 设置

设置包括：

- 外观：模式、样式、调色板、浅色或深色主题。
- 语言：英文或中文。
- 模型：端点、模型 ID、密钥、harness 与连接状态。
- 常驻约定：为未来跟进提供有范围的授权。
- 临时 YOLO 授权；生效时显示撤销操作。
- 五种工作视图与恢复默认值。

外观偏好保存在当前浏览器，没有账号或跨设备同步。模型与连接器设置保存在本地私有文件。

## 加载、空与错误状态

工作区优先显示已记录状态，而不是解释性文案。加载中或为空的来源会平静地说明正在发生什么、你可以做什么。未知或未确认的结果会明确标注。模拟演示记录有清晰标记，绝不会出现在正常启动中。

界面背后的数据模型见[架构](architecture.md)。任务结果与批准见[工作流](workflows.md)。
